## Overview
- 自身をさらに高めようと、啓発本を購入したことがありました。そこには自分を戒める言葉、ハッとさせる言葉がたくさんあり、本当に買ってよかったと思いました。
- しかし問題だったのは、それらの言葉が多すぎて覚えていられないことでした。自分を変えるには、日々これらの言葉を胸に留めて行動をすることです。しかし忘れていてはそれができません。加えて思い出そうにも、毎回何ページの何行目という正確な場所まで覚えていることもできません。メモアプリに記録しようにも、次の日にはそのメモがどこへ行ったのかを探す必要があります。
- 本アプリは、このように心得ておきたい言葉へのアクセスを簡単にするために作成しました。アプリを開くと自身が登録した言葉にすぐアクセスできます。さらに、ホーム画面にはランダムで自身が登録した言葉が表示されるため、アクセスする機会も増えます。
